# SIH26003

Adaptive cognitive engagement platform for dementia care.

## Architecture

Frontend
- React
- TypeScript
- Tailwind

Backend
- FastAPI
- PostgreSQL
- SQLAlchemy

## Activities

1. Familiar Object Categorization
2. Cultural Familiarity / Reminiscence
3. Familiar Pairs Matching
4. Everyday Routine Sequencing

## Core Principle

The system adapts task challenge and assistance based on
observable interaction signals. It does not diagnose, assess,
or infer cognitive status.
